# 🛒 MarketPro – Angular Marketplace Frontend

MarketPro is a **modern, feature-rich marketplace / e-commerce frontend** built with **Angular**.  
It focuses on modular UI components, clean layout separation, and reusable services, making it a solid base for real-world shopping platforms.

---

## 🌐 Live Demo

🚀 **Live URL:** https://market-pro-green.vercel.app/

---

## ✨ Key Features

- 🧩 Modular Angular component architecture
- 🏠 Home page with banners, categories, offers & flash sales
- 🛍️ Product listing, shop & product detail pages
- 🛒 Cart & Wishlist functionality (UI ready)
- 👤 Profile & Vendor pages
- 📰 Blog & Contact pages
- 🧱 Clean layout separation (Header / Footer)
- 🎨 Rich UI assets & custom fonts included
- ⏱️ Timer service for flash deals & offers

---

## 🧑‍💻 Tech Stack

- **Angular** (Standalone components & routing)
- **TypeScript**
- **HTML5 / CSS3**
- **Angular Services & Models**
- **Vercel** (Deployment)
